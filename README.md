# 民间恶魔与道德恐慌 · 1964 Mods & Rockers 交互档案

自包含单文件交互网页（原生 HTML/CSS/JS + Three.js 3D 建模）。

## 如何打开

- 直接双击打开 `1964-民间恶魔与道德恐慌.html`（推荐 Chrome / Edge）。
- **首次打开建议联网**：3D 人物展厅依赖 CDN（jsDelivr 的 Three.js）。页面中文字体已内置系统字体回退（宋体 / 微软雅黑等），断网也不会乱码；3D 引擎断网时自动回退为静态档案视图，页面其余功能不受影响。
- 背景音乐为网页内置的 **Web Audio 实时合成**，不依赖任何外部音频文件，零版权风险；同目录下旧的 `assets/*.wav` 已不再被页面引用，可保留或删除。

## 内容结构（6 个章节）

1. **Hero 首屏**：60 年代海滨海报风 + 胶片颗粒动画
2. **两个部落**：Mods / Rockers 档案卡 + **3D 人物群像展厅**（6 个真人比例、有面孔的低多边形人物，Mod 群与 Rocker 群各 3 人，配清晰可辨的小绵羊与大排量摩托，可拖动旋转；8 个小红点查看细节，工具栏可切换派克大衣 / 头盔 / 墨镜、聚焦任意群体）
3. **复活节海滨冲突**：可交互海滩模拟（画面下方带**图例**标识 Mod / Rocker / 警察 / 记者 / 被捕；警察会主动走向青年并打上“被捕”标记；点击青年查看“暴徒”档案）、与速度同步推进的连续时间轴、三地档案卡
4. **媒体机器**：三个旋钮（夸张与扭曲 / 预测 / 象征化）实时改写**中英双语报纸头版**、公众恐慌仪表、报道 vs 事实对照柱状图
5. **道德恐慌**：科恩五特征翻面卡、偏差放大螺旋循环演示（可逐轮点击）、道德恐慌循环示意图
6. **尾声**：主编选择题测验 + 出处声明

## 背景音乐（BGM）

整页循环同一支背景音乐：一段由 **Web Audio 实时合成**的柔和 60 年代风氛围和声（Am–F–C–G 进行）。它不依赖任何第三方音频文件，因此完全不存在版权风险。首次点击或滑动页面后开始播放（受浏览器自动播放策略限制），右上角按钮可一键静音 / 开启。

> 如需改用某首具体的无版权音乐（Pixabay CC0、Incompetech CC-BY 等第三方曲目），把音频文件命名为 `bgm.mp3` 放进同目录后告知作者，即可接入并自动署名。

## 史实与数据来源

- 克拉克顿（1964-03-30）约 97 人被捕、损失约 £213：Mirror, "Mods v Rockers! 1964 beach battles" (2014)
- 布莱顿约 3,000 青年涌入、76 人被捕：University of Brighton Blog (2019)；Nostalgia Central
- 马盖特约 51 人被捕、法官重判：Subcultz 档案
- 理论框架：Stanley Cohen《Folk Devils and Moral Panics》(1972)；"道德恐慌"三机制（夸张与扭曲 / 预测 / 象征化）：Media Studies

页面内全部"报道口径"数字为当时新闻宣称的约数，用于与警方逮捕记录对照，非精确统计；所有可视化均为示意。
