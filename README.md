# 民间恶魔与道德恐慌 · 1964 Mods & Rockers 交互档案

自包含单文件交互网页（原生 HTML/CSS/JS + Three.js 3D 建模）。

## 如何打开

- 直接双击打开 `1964-民间恶魔与道德恐慌.html`（推荐 Chrome / Edge）。
- **首次打开建议联网**：3D 人物展厅与页面字体依赖 CDN（jsDelivr 的 Three.js、飞书字体镜像）。断网时会自动回退为静态档案视图，页面其余功能不受影响。
- 请勿移动、重命名或删除同目录下的 `assets/` 文件夹——页面用相对路径引用其中的 3 支音乐。

## 内容结构（8 个章节）

1. **Hero 首屏**：60 年代海滨海报风 + 胶片颗粒动画
2. **两个部落**：Mods / Rockers 档案卡 + **3D 人物建模展厅**（低多边形人物、小绵羊与摩托，可拖动旋转，8 个热点点击查看细节，工具栏可切换派克大衣 / 头盔 / 墨镜、聚焦任意人物）
3. **复活节海滨冲突**：可交互海滩模拟（点击青年查看"暴徒"档案）、连续时间轴、三地档案卡
4. **媒体机器**：三个旋钮（夸张与扭曲 / 预测 / 象征化）实时改写出报纸头条、公众恐慌仪表、报道 vs 事实对照柱状图
5. **道德恐慌**：科恩五特征翻面卡、偏差放大螺旋循环演示（可逐轮点击）
6. **落差**：报道与现实对比滑杆、标签生成器（自选穿着/代步/音乐生成"头条"）
7. **声音工作室**：3 支豆包 AI 生成的 60 年代风格音乐（Mods' Beat / Rockers' Ride / Newsreel Tension），带唱片旋转与均衡器可视化；另有 6 种 Web Audio 实时合成现场音效（海浪/海鸥/引擎/人群/快门/警哨）
8. **尾声**：主编选择题测验 + 出处声明

## 史实与数据来源

- 克拉克顿（1964-03-30）约 97 人被捕、损失约 £213：Mirror, "Mods v Rockers! 1964 beach battles" (2014)
- 布莱顿约 3,000 青年涌入、76 人被捕：University of Brighton Blog (2019)；Nostalgia Central
- 马盖特约 51 人被捕、法官重判：Subcultz 档案
- 理论框架：Stanley Cohen《Folk Devils and Moral Panics》(1972)；"道德恐慌"三机制（夸张与扭曲 / 预测 / 象征化）：Media Studies

页面内全部"报道口径"数字为当时新闻宣称的约数，用于与警方逮捕记录对照，非精确统计；所有可视化均为示意。
